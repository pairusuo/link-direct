# 一键跳转助手 (Link Direct)

这是一个基于 Chromium 内核的浏览器插件，主打“一键跳转”体验。目前主要用于解除在微信电脑端点击外部链接时出现的“如需浏览，请长按网址复制后使用浏览器访问”等跳转限制，未来也可扩展支持更多平台的拦截页面。

### 功能

在指定的微信拦截页面（`weixin110.qq.com/.../newredirectconfirmcgi`）上，自动识别目标URL，并在原有的提示语下方展示两个按钮：

- **复制链接**：一键将目标URL复制到剪贴板。
- **一键访问**：无需复制，一键直接跳转到目标网站。

### 如何安装测试

1. 在 Chrome 或 Edge 浏览器中输入 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启右上角的 **开发者模式 (Developer mode)**。
3. 点击 **加载已解压的扩展程序 (Load unpacked)**。
4. 选择本项目所在的文件夹 `link-direct`。
5. 插件加载成功后，您可以尝试在电脑端微信打开一个被拦截的外部链接，测试效果。

### 文件结构

- `manifest.json`: 插件的核心配置，设置为 Manifest V3，并限定在指定的微信拦截页面运行。
- `src/content.js`: 内容脚本，负责解析页面中的目标 URL，并动态注入交互按钮。
- `src/content.css`: 按钮及容器的样式文件，采用类似微信的主题绿 (#07C160)。

### 设计思路与核心优势 💡

市面上虽然存在一些“外链跳转”插件，但本插件针对特定痛点进行了极简与克制的设计：

1. **🔒 极致的隐私与安全保护 (最小权限原则)**
   不同于其他同类插件动辄申请接管所有网站（`*://*/*`）的读取权限，本插件在配置文件中**仅强制声明**对 `*://weixin110.qq.com/*` 这一个拦截域名的访问权。绝不窃取或过度收集您的日常网页浏览数据，让您用得绝对安心。

2. **🎯 专注解决“无法点击”的死角**
   很多传统的“自动点击”插件是为了帮您省去点击“继续访问”那一下。但遇到微信彻底不提供跳转按钮、逼迫您“长按网址复制”的死角页面时（本插件的核心应用场景）就会完全失效。我们通过动态注入UI按钮，完美补充了这一体验断层。

3. **🎈 轻巧零负担，无后台驻留**
   整个插件代码极简，不含任何花哨的多余功能或广告组件。它没有后台常驻的 Service Worker 进程，在您不访问微信拦截页时，它完全处于睡眠状态，**零内存占用**，绝对不拖慢您的浏览器速度。

### 使用命令打包，剔除Mac隐藏文件

```bash
zip -r link-direct.zip manifest.json icons src -x "*.DS_Store" -x "__MACOSX"
```
